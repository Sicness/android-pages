# CLAUDE.md

## Что это

Страница «Наши приложения» по адресу `android.darklogic.ru`: список наших
Android-приложений. На неё ведёт пункт меню из каждого приложения, чтобы
пользователи одного узнавали о других. Ту же страницу можно указать как сайт
разработчика в сторах.

Список живёт здесь, а не в коде приложений: новое приложение появляется у всех
пользователей сразу, без релизов.

## Как устроено

Статическая страница без сборки, хостинг — GitHub Pages из ветки `main`.

- `index.html` — вёрстка, стили и скрипт в одном файле. Внешних ресурсов нет:
  системный шрифт, картинки лежат рядом.
- `apps.json` — данные о приложениях. Страница рисуется из него; позже из него же
  приложения смогут брать список для нативного показа.
- `assets/<id>/icon.webp` — иконка, 192 px.
- `assets/<id>/<язык>/N.webp` и `N-thumb.webp` — скриншот и его уменьшенная копия
  высотой 360 px. Полный размер грузится только по нажатию.

Все пути относительные: страница работает и на своём домене, и по адресу
`sicness.github.io/android-pages/`.

Локально: `python3 -m http.server 8787` в корне. С `file://` не работает — данные
загружаются через `fetch`.

## Параметры ссылки

Приложение открывает страницу во внешнем браузере и передаёт:

| Параметр | Значения | Что делает |
|---|---|---|
| `utm_source` | `id` приложения из `apps.json`: `mds`, `react2players` | Скрывает приложение, из которого пришли. Google Analytics сам показывает метку в отчётах по источникам. |
| `lang` | `ru`, `en` | Язык страницы и список приложений. |
| `store` | `gp`, `rustore` | Показывает кнопку только этого стора. |

Без параметров показываются все приложения для языка браузера.

## Правила

- **Язык.** Русскоязычный — тот, у кого русский есть где угодно в списке языков
  системы, либо первый язык украинский, белорусский или казахский. Приложение
  считает это по системной локали и шлёт `lang`; МДС всегда шлёт `ru`. Без `lang`
  страница применяет то же правило к языкам браузера. Остальным — английский.
- **Список для языка** — приложения, у которых в `apps.json` есть блок `content`
  на этом языке. У МДС он только русский, поэтому в английском списке её нет.
- **Сторы.** С параметром `store` — только этот стор. Без него русскоязычным
  показываются Google Play и RuStore, остальным — только Google Play.
- **Установки.** Ссылка на Google Play несёт `referrer` с `utm_source` приложения,
  из которого пришли, и `utm_medium=apps_page`.
- **Скриншот** раскрывается по нажатию; кнопка «Назад» закрывает его, а не уводит
  со страницы.
- **Бренд** Darklogic не продвигаем: в шапке нет ни названия, ни логотипа.

## Как добавить приложение

1. Добавить объект в `apps.json`: `id`, `package`, ссылки в `stores`, блок
   `content` на каждый язык с `name`, `tagline`, `description` и числом скриншотов.
2. Положить иконку и скриншоты в `assets/<id>/`. Материалы берём из листингов
   в сторах; картинки храним здесь, а не ссылаемся на серверы сторов.
3. Порядок на странице — порядок в файле.

## Аналитика

Счётчик — Google Analytics в отдельном проекте Firebase `android-c1827`: у каждого
приложения свой проект, страница не принадлежит ни одному из них. Идентификатор
потока лежит в `GA_ID` в `index.html`; пустая строка выключает счётчик.

События: стандартный `page_view`, `screenshot_open` (`app_id`, `index`) и
`store_click` (`app_id`, `store`). Со всеми событиями уходят `from_app`,
`page_lang` и `store_ctx`.

Сквозную цепочку «открыл из МДС — установил другое приложение» считает Firebase
в самих приложениях: открытие пункта меню и `referrer` установки.

## Почему так

- **GitHub Pages**, а не Cloudflare: Cloudflare в России замедлен. Доступность
  GitHub у нашей аудитории меряет МДС (событие `net_call`, `target=probe_github`).
  Если данные окажутся плохими, запасной вариант — Yandex Object Storage; свой
  домен позволяет переехать сменой одной DNS-записи.
- **Репозиторий публичный**: на бесплатном тарифе GitHub Pages иначе не работает.

## Не сделано

- Параметры событий (`app_id`, `store`, `from_app`, `page_lang`, `store_ctx`) не
  зарегистрированы в Google Analytics как пользовательские измерения; без этого
  их нет в отчётах консоли.
- Пункта меню в приложениях нет. В МДС нужны пункт в боковом меню, ссылка из
  Remote Config, событие Firebase на открытие. У нерусскоязычных пользователей
  «Реакции 2 Игрока» ссылка пустая и пункт скрыт, пока нет третьего приложения.
- Точка «новое» на пункте меню: версия списка в Remote Config против последней
  увиденной. В `apps.json` для этого есть поле `version`.
- Порядок приложений, зависящий от источника.
